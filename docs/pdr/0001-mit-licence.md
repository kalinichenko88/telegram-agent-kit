# 0001 MIT licence

- Status: accepted
- Level: project
- Date: 2026-06-21

## Decision

We publish the kit as open source under the MIT licence, on npm and on GitHub.

## Rests on

- The project has no income and no paid service to protect, `PRODUCT.md`.
- npm and GitHub are free for a public package and repository.

## Revisit when

A contributor or a user asks for another licence, or the project starts to
earn money.

## Options considered

- MIT: the shortest permissive licence; any bot can use the kit.
- Closed source: no outside users, no outside reports.
